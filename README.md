# 物理社功勋系统

Material Design 风格的四组功勋管理系统，基于 EdgeOne Pages 云函数 + React 前端。从传统积分系统升级为双录入账功勋体系，支持动态权限组、社团组管理、批量社费导入、维护模式等功能。

## 快速启动

```bash
npm install
npm run dev            # Vite 前端开发 (:5173)
npm run dev:server     # Express + Vite (:8791 / :5173)
npm run dev:functions  # EdgeOne Pages 本地模拟 (:8088)
```

默认管理员账号（可通过环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 覆盖）：

- 用户名：`admin`
- 密码：`Physics@2026`

## 技术架构

```

    ledger/         # 流水端点
  lib/              # 共享库（auth、database、jwt、response）
src/                # React 前端
  features/         # 功能页面
    admin/          # 管理面板组件
    auth/           # 登录/注册
    dashboard/      # 总览、成员、统计

    profile/        # 个人菜单
  layout/           # AppShell（导航、侧边栏）
  components/       # 通用组件
  utils/            # 格式化工具
```

## 功勋体系（双录入账）

系统以"功勋"替代传统积分，每 1 功勋对应 1 元真实资金，保证账目平衡。

### 四个资金池

| 池子 | ID | 说明 |
|------|-----|------|
| 固定资金池 | `pool_fixed` | 社团公共资金，用于物资、垫付、奖励注资 |
| 项目待结算池 | `pool_settlement` | 临时中转，收入先入此池，扣除成本后利润转固定池 |
| 奖励池 | `pool_reward` | 固定池中的锁定部分，专用于发奖励 |
| 个人账户 | （社员 ID） | 社员个人功勋余额 |

### 操作类型

| 操作 | 说明 |
|------|------|
| 铸造（casting） | 真实资金进入系统，功勋增加 |
| 销毁（destruction） | 资金离开系统，功勋消灭 |
| 社费拆分（dues_split） | 新社员缴费按比例分配固定池和个人 |
| 项目结算（project_settle） | 待结算池 → 付成本 → 利润转固定池 |
| 奖励填充（reward_fill） | 固定池 → 奖励池 |
| 奖励发放（reward_distribute） | 奖励池 → 社员 |
| 注销退款（refund） | 销毁功勋 + 取消激活账户 |
| 转账（transfer） | 池间功勋转移 |

## 权限系统

### 动态权限组

- 内置基础角色：`public`（公开）、`member`（社员）
- 管理员 `admin` 始终全权限
- 可创建自定义权限组（如"社团策划层"），所有非公开/非社员角色自动继承社员权限
- 每个页面的可见角色可在权限台独立设置

### 页面与权限对应

| 页面 | 默认可见 | 说明 |
|------|---------|------|
| 总览 | 公开 | 小组概览和功勋排行 |
| 成员 | 社员 | 成员目录 |
| 我的明细 | 社员 | 个人功勋流水 |
| 统计台 | 社员 | 统计快照和分录检查 |
| 社团管理台 | 策划层 | 功勋操作（铸造、拆分、结算等） |
| 管理员权限台 | 管理员 | 权限管理、成员管理、邀请码等 |

能看见某个页面就有权限使用对应功能。

## 主要功能

### 社团管理台
- 功勋铸造/销毁
- 池间转账
- 社费拆分（单人或批量 CSV 导入）
- 项目结算（收入−成本=利润）
- 奖励池填充分发
- 注销退款

### 批量社费导入
- 支持 CSV 文件（格式：`用户名,金额[,组别名]`）
- 自动匹配现有用户或创建新账户（随机密码）
- 预览拆分结果，可手动调整
- 完成后下载含密码的 CSV

### 动态社团组
- 新增/编辑/删除社团组，设置边框颜色
- 解散组时成员自动退回无组状态（10 秒确认倒计时）

### 维护模式
- 管理员一键开启，强制退出非管理员
- 仅管理员可登录，所有 API 阻止非管理员请求
- 前端显示黄黑警戒线和红色警告条

### 管理员权限台
- 成员管理（角色、职务、组别、批量改组、强制改密、强制删除）
- 邀请码管理（创建、停用、复制）
- 权限台（页面可见范围表格、侧边栏在线用户配置）
- 侧边栏管理（导航顺序调整）

### 前端特性
- Hash 导航（`#/overview`）
- 深色/浅色/自动主题切换
- 全局水印（未登录 ASJPHYC，已登录 ASJPHYC-@用户名）
- 鱼骨屏骨架加载动画
- API 请求全屏提示（显示正在操作的端点）
- 错误边界（显示堆栈，提示截屏上报）
- 移动端自适应

## 部署

项目通过 EdgeOne Pages 部署。`functions/` 目录中的云函数自动注册为 API 端点。前端通过 Vite 构建到 `dist/`。

```bash
npm run build                # 构建前端
npx edgeone pages deploy     # 部署到 EdgeOne
```
